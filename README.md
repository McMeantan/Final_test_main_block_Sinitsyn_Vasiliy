# Программа, выделяющая из массива строк строки длиной меньше или равной трём символам

Эта программа позволяет ввести с клавиатуры некий массив строк, проанализировать каждую строку на соответствие условию (число символов <= 3) и сформировать из строк, удовлетворяющих этому условию, новый массив.

## Ввод массива строк

Сначала программа выводит на консоль сообщение **"Введите строки через пробел:"**. Когда пользователь заканчивает ввод и нажимает клавишу Enter, она преобразует введённую строку в массив строк по разделителю "пробел".

## Анализ строк на соответствие условию

1. Перед анализом формируется список *resultList* для динамического добавления строк.
2. Каждая строка проверяется на соответствие условию с помощью цикла *foreach* и в случае, если её длина не превышает 3 символов, добавляется в вышеупомянутый список.

## Финальная часть работы

1. Список *resultList* преобразуется в массив с типом данных *string[]*.
2. Массив строк, удовлетворяющих условию, выводится на консоль.
